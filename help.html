How can we help?

Find quick answers about tracking a package with Snabb Leverans.

Track a package

Go to the home page, enter your Order ID, then select Track. Choose one of the sample IDs shown below the search field to try the demo.

Where can I find my Order ID?

Use the Order ID provided with your shipment. This demo accepts the sample IDs listed on the home page.

My Order ID was not found

Check that you entered the ID correctly. The demo only displays packages included in its sample data; an ID that is not listed there will not return a result.

What do the tracking statuses mean?

In Warehouse
The package is being prepared or stored at a warehouse.
Picked Up
The carrier has collected the package from the sender.
In Transit
The package is moving through the delivery network.
At Collection Point
The package has reached a collection point. Check the carrier's instructions for pickup details.

Is the estimated delivery time guaranteed?

No. It is an estimate shown with the sample package data and may change.

This project is a demonstration. Its package records are sample data, not live shipment updates.
